              🚫 Strict Customer Privacy & Data Isolation Guarantee
            
    
            
    
              The Hartford never accesses personal files, communications, or sensitive business records. The OAuth connection is strictly limited to metadata and security posture flags.
            
    
          
    

          
    
            
    
              ✕
              
    
                
    We NEVER read or access Emails, Chats, or Calendar entries
    
                
    No message bodies, subject lines, attachments, contact lists, or recipient addresses are ever viewed or fetched.
    
              
    
            
    

            
    
              ✕
              
    
                
    We NEVER access Google Drive files, documents, or spreadsheets
    
                
    We only confirm that automated security scanning rules are turned on. Your actual files remain 100% private.
    
              
    
            
    

            
    
              ✕
              
    
                
    We NEVER see or store Passwords, Secret Keys, or Recovery Codes
    
                
    Google only provides an anonymous boolean verification flag (e.g., isEnforcedIn2Sv = true).
    
              
    
            
    

            
    
              ✕
              
    
                
    We NEVER retain employee rosters or IT configuration files
    
                
    All telemetry is processed in volatile server memory (RAM) and immediately discarded. Zero customer data is saved to disk or database.
    
              
    
            
    

            
    
              ✕
              
    
                
    We CANNOT modify, change, or delete any customer settings
    
                
    All requested OAuth scopes are explicitly restricted to .readonly and .user.security. Write or admin actions are cryptographically impossible.
    
              
    
            
    
          
    
        
    

        
        
    
          
    
            
    How Zero-Retention Works (SOC 2 / ISO 27001)
    
            
    
              Project Beacon is engineered around a strict Ephemeral Lifecycle Policy. Instead of storing customer IT architectures, we produce an immutable cryptographic receipt:
            
    
          
    

          
    
            
    
              
    Step 1
    
              
    Ephemeral Query
    
              
    Short-lived OAuth token reads 4 high-level posture booleans into RAM.
    
            
    
            
    →
    
            
    
              
    Step 2
    
              
    Actuarial Rating
    
              
    Hartford rating engine computes tier discount (up to 25%) in <200ms.
    
            
    
            
    →
    
            
    
              
    Step 3
    
              
    SHA-256 Hashing
    
              
    Verified claims are hashed into a tamper-evident attestation receipt.
    
            
    
            
    →
    
            
    
              
    Step 4
    
              
    Memory Discard
    
              
    Raw Google responses and tokens are purged. Zero data retained.
